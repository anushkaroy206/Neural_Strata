# Neural Strata — frontend

Control-room dashboard for slope-stability monitoring, underground evacuation routing and the underground blackbox / cloud-sync chain. Pure HTML + CSS + JavaScript, zero runtime dependencies.

**`index.html` at the project root is the whole app in one self-contained file** — open it directly in a browser (it runs in Sim mode), drop it on any static host, or let the gateway serve it. The editable sources are in `src/`; `npm run build` regenerates `index.html` from them.

## Quick start

```bash
npm start          # serves index.html + a mock gateway API at http://localhost:8080
npm run dev        # same, but serves the modular sources in src/ (edit → reload)
```

Open http://localhost:8080 — the header shows **Online / LIVE** because the mock gateway answers every `/api/*` route. Sign in with one of the demo accounts:

| Role | ID | PIN |
|---|---|---|
| Mine Operator | `ECL-4471` | `4471` |
| Mine Planner / Geologist | `GEO-2290` | `2290` |
| DGMS Regulator | `DGMS-1107` | `1107` |

Other scripts:

| Command | What it does |
|---|---|
| `npm run serve` | static server only — the dashboard falls back to its built-in simulator (**Sim mode**) |
| `npm run check` | verifies every linked asset in `src/` exists, load order is intact, all scripts parse, and `index.html` is not older than `src/` |
| `npm run build` | inlines `src/` into `index.html` (one file, ~1 MB, no server needed) — run it after every change in `src/` |

Requires Node ≥ 18. There is nothing to install.

## Pointing the dashboard at a real gateway

* Same origin (recommended): let the Flask app serve this folder and answer `/api/*` — nothing to configure.
* Different origin: set `window.NEURAL_STRATA_API = 'https://gateway-host:5000'` in `src/js/00-config.js` (then `npm run build`), or open `index.html?api=https://gateway-host:5000`. The gateway must allow CORS.

The full request/response contract, polling intervals and fallback rules are in **[docs/API.md](docs/API.md)**. `mock/server.js` implements the same contract, including a `POST /api/mock/faults` helper to demonstrate SD / USB / cloud / power faults on the live feed.

## What the rest of the project has to provide

| Component | Interface to this frontend |
|---|---|
| Surface gateway (Flask + SQLite on the control-room laptop) | the eight routes in `docs/API.md`; `blackbox` + `cloud` blocks in `/api/extended`; `POST /api/cloud/force_sync` |
| Main hub M-01 firmware (ESP32, MicroSD on VSPI) | via the gateway: `chunk_id`, `row`, `free_mb`, `sd_ok`, `usb_ok`, `power_ok`, `retained[]` |
| Central Mining Cloud | via the gateway: `cloud.online`, `pending`, `sent`, `last_upload`, `last_ack` |
| ML / forecasting service | `GET /api/ai` (`status: ACTIVE` + per-node `forecasts`) |
| Identity provider | replace the demo `ROLES` table in `src/js/09-access-control.js` |

## Deploying

Copy `index.html` anywhere (kiosk browser, the Flask `static/` folder, a USB stick) — it is the complete application and still honours `?api=`. After editing anything in `src/`, run `npm run build` so `index.html` picks up the change.

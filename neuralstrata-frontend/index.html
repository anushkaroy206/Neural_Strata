NO INJECTION ARMED
Every scenario injection in the build lives here — the overview card and the keyboard shortcuts both open this console rather than duplicating the buttons. Injections push an accelerating tertiary-creep signature into the simulated potentiometer feed: CREEP plateaus sub-critical and stabilises; FAILURE crosses 3.0 mm/s² at about 3 seconds and runs to full-scale displacement, dropping the child node off the mesh so the Command Centre reroutes around it.

Entrances: WEST PORTAL (L1 inclined) · WEST AIR SHAFT (L2 vertical) · EAST AIR SHAFT (shared surface → L1 → L2) · SECONDARY EMERGENCY INCLINE (east) · CROSS SHAFT (L1 ↔ L2). The mesh sits NW of the surface, so a failing node undermines that level's west entrance — think of a worker stuck at a stope face: the map runs a real shortest-path (Dijkstra) from each crew position to the nearest open entrance, so if one entrance is blocked they exit the other (or cross to the other level via the cross shaft). Evacuating crew walk the green route to the exit; if no entrance is open, they are routed to the nearest hub (SHELTER IN PLACE). Click a level band to zoom into that level; click the map to zoom back out.
